# Monopoly

A local pass-and-play Monopoly game for 2–4 players sharing one device.

## Run locally

Use Node.js 26.13.1. Install dependencies with the pinned pnpm version:

```sh
npm exec --yes --package=pnpm@12.21.0 -- pnpm install --frozen-lockfile
```

Start the game:

```sh
pnpm dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
